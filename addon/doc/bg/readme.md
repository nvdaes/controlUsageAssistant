# Асистент за работа с контроли (Control Usage Assistant) #

* Автор: Joseph Lee, Noelia Ruiz Martínez


Използвайте тази добавка, за да разберете как да взаимодействате с фокусираната контрола.
Натиснете NVDA+H, за да получите кратко помощно съобщение за взаимодействие с фокусираната контрола, като полета за отметка, полета за редактиране и т.н.

Отидете в менюто на NVDA, подменюто Настройки, диалоговия прозорец Опции, категорията Асистент за работа с контроли, за да конфигурирате настройките на добавката:

* Автоматични съобщения за фокус: Отметнато по подразбиране.
* Въведете съобщението, което да се използва, когато даден обект може да бъде активиран: Можете да включите кратко съобщение, указващо жеста по подразбиране или вашия конфигуриран такъв, за да знаете дали текущият обект има свързано действие при натискане на жест като например NVDA+Enter при обектна навигация.
* Избор на изходни режими за автоматичните съобщения: Този списък с полета за отмятане позволява да изберете реч и брайл.
* Промяна на височината на гласа за автоматичните съобщения: Това въртеливо поле позволява да се зададе промяната на височината, когато NVDA чете автоматични съобщения (от -30 до +30).
